# iCal をカレンダーに追加する

## Google カレンダーの手順

1. Google カレンダーの設定ページを開きます (<https://calendar.google.com/calendar/u/0/r/settings>)
2. 「カレンダーを追加」→「URL で追加」と進みます (<https://calendar.google.com/calendar/u/0/r/settings/addbyurl>)
3. 発行された URL を入力します。 絶対に「一般公開する」にしないでください！
4. 「追加する」をすれば完了です
5. 設定したい場合には「他のカレンダーの設定」から変更しましょう
